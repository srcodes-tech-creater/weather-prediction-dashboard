# 🌦️ Weather Forecasting Dashboard

A real-world weather forecasting dashboard built using Python, Streamlit, OpenWeather API, Data Science, and Machine Learning.

## 🚀 Features

- Real-time weather information
- City-based weather search
- Temperature, humidity, pressure, and wind speed
- 5-day weather forecast
- Temperature trend visualization
- Humidity trend visualization
- Statistical weather analysis
- Machine Learning temperature prediction
- Interactive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenWeather API
- Pandas
- Requests
- Scikit-learn
- Linear Regression

## 🤖 Machine Learning

The application uses a Linear Regression model to analyze temperature trends and estimate future temperature values.

## 📊 Data Science Analysis

The dashboard calculates:

- Minimum temperature
- Maximum temperature
- Average temperature
- Average humidity
- Temperature trends
